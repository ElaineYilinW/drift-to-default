# 探针的峰来自哪几个时间频率？（频带探针，2026-10-29，探索性，未预注册）

## 问题
- 注意力探针（实验记录 30）显示，查询对 sink 的注意力份额在距离 71、134、203、266 个潜在帧处有尖峰，间隔约 66 帧；突跳就发生在 sink 经过这些距离的时候（研究 25–28）。
- Wan2.1 的时间 RoPE 有 22 个频率，频率 j 的周期是 2π·10000^(2j/44) 个潜在帧：
  - j0 6.3，j1 9.5，j2 14.5，j3 22.1，j4 33.5，j5 51.0，j6 77.5，j7 117.7；
  - j8–j21 更长（179 到约 4.1 万帧）。
- 问题是：这些峰是哪几个频率造成的？

## 方法
- 代码：
  - `jobs/patch_sf_sinkband.py` 打在 Self-Forcing-c 上（`jobs/setup_sf_c.sh`），生成器 `hold_gen_sinkband.py`，运行脚本 `jobs/run_sinkband.sh`；
  - 分析 `analysis/analyze_sinkband.py`，结果在 `results/corr/sinkband_out/sinkband.json`。
- 设置：
  - 2 个开头（rx02、gx02），原始位置的 sink 3，块 60 和 132，距离 3–300；
  - 先把 sink 的键放到参考距离 20（重新旋转的位置），再只把一个频带的频率转到网格距离 D，其他频率留在 20。
  - 频带包括：全部、空、四组（j0–3、j4–7、j8–11、j12–21）各自"只有"和"去掉"，以及 j0–j11 每个单独"去掉"。
- **峰的对比度：** 4 个峰处的份额均值减去距离 10–300 的份额中位数。
- 主峰的判定规则与 `analyze_sinkprobe_long.py` 相同：突出度 ≥ 0.04。

## 结果

| 频带 | 对比度 | 与全部频率曲线的相关 | 主峰（潜在帧） |
|---|---|---|---|
| 全部 | +0.058 | 1 | 71、90、134、203、266 |
| 只有 j0–3 | +0.018 | 0.68 | 222 |
| 只有 j4–7 | +0.025 | 0.59 | 69、103、169、203、237 |
| 只有 j8–11 / j12–21 | 约 0 | 0.32 / 0.31 | 无 |
| 去掉 j0–3 | +0.022 | 0.66 | 102、169、203、237、270 |
| 去掉 j4–7 | +0.017 | 0.75 | 无 |
| 去掉 j8–11 | +0.060 | 0.99 | 与全部相同 |
| 去掉 j12–21 | +0.057 | 1.00 | 与全部相同 |
| 去掉 j3 | +0.038 | 0.84 | 33、103、134、165、203、234、278 |
| 去掉 j4 | +0.018 | 0.77 | **无** |
| 去掉 j0、j1、j2 | 0.048–0.064 | 0.92–0.97 | 主峰保留，另有小峰 |
| 去掉 j5–j11 中任一个 | 0.055–0.059 | ≥ 0.99 | 与全部相同 |

- 第一个探针的 4 个峰在这里都出现了。这次只用了 4 条曲线，另外在 90 处多出一个刚过门槛的峰（突出度 0.044）。

## 解读
- **j4（周期 33.5 帧）是必需的：** 只去掉它，所有主峰都消失（对比度从 0.058 降到 0.018）。
- **只有 j4–7 时得到一把周期约 34 帧的梳子：** 峰在 69、103、169、203、237。
- **j3（周期 22.1 帧）去掉梳子的奇数齿：**
  - 33.5 ≈ 1.5 × 22.1，所以 j4 的奇数倍上 j3 正好反相，偶数倍上同相（67 ≈ 2 × 33.5 ≈ 3 × 22.1）。
  - 剩下的峰间隔约 67 帧，这就是看到的 71、134、203、266。
  - 去掉 j3 时奇数齿回来：33、103、165、234。
- **长周期的频率（j5 以上，周期 ≥ 51 帧）不影响峰的位置：**
  - 去掉 j8–11 或 j12–21，曲线几乎不变（r ≥ 0.99）；
  - 单独去掉 j5–j11 中任一个也一样。
- **短周期的 j0–j2 只调整峰的形状。**
- **结论（探索性）：** 突跳的时间由 sink 在两个时间频率上的相位决定。j4 给出周期约 34 帧的对齐，j3 隔一个去掉一个。这比"位置周期性"（LoL）更具体：可以指出是哪两个频率，并预测改动它们之后突跳在哪里。

## 可以检验的预测（预注册 34）
在生成时只把 sink 的某些频率固定在距离 20，其他频率保持原始位置：
- 固定 j4：突跳消失；
- 固定 j3：16.5 秒的突跳消失，在 7、24.5、40、57.25 秒出现新的突跳（"去掉 j3"曲线上新的峰 33、103、165、234；起点 = (P − 5)/4 秒）；
- 固定 j8–11（对照）：突跳不变。

## 补充：哪些层、头和去噪步骤带有峰（探索性）
- 脚本 `analysis/analyze_sinkprobe_heads.py`，用第一个探针的数据（4 个开头 × 20 个块），结果 `results/corr/sinkprobe_out/sinkprobe_heads.json`。
- 峰的对比度（4 个峰的份额减去中位数）：
  - **每一层都有：** 30 层全部为正（0.011–0.118），第 8、12 层最高（0.12）；
  - **大多数头都有：** 360 个"层 × 头"中 272 个的对比度 > 0.01。最强的 10% 的头只占正对比度总和的 39%，最强的几个头对比度 0.3–0.5（第 12 层头 2、第 23 层头 1、第 12 层头 8）；
  - **每个去噪步骤都有：** 0.056、0.055、0.052、0.047、0.042，随步骤略降。
- **解读：** 峰不是少数几个"sink 头"的行为，而是分布在几乎所有层和头上。这与位置上的解释一致：所有头用的是同样的 RoPE 频率，所以 sink 在 j3、j4 上的相位对齐会同时影响所有头，只是程度不同。
