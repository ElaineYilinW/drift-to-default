# 探索：sink 在哪些距离上得到注意力？（注意力探针，2026-10-28，不属于任何预注册）

## 目的
- sink 留在原始旋转位置时，持续度在约 17、33、51 秒突然上升，开头的场景也在这些时刻回来（预注册 10、16、21）。
- 之前的猜测是这些时刻对应某个旋转频率的周期（约 70 个潜在帧）。这个说法没有直接证据。
- 这里直接测量：在每个查询–sink 距离上，模型会把多少注意力分给 sink。

## 方法
- **代码：**
  - `jobs/patch_sf_sinkpos.py` 给 Self Forcing 的一个独立副本（Self-Forcing-b，符号链接树，只有 `wan/modules/causal_model.py` 是实际文件）加两个环境变量开关，正在运行的其他研究不受影响：
    - SF_SINK_MODE：移动 sink 的旋转位置（off:N 往后移 N 帧；dist:D 固定在距离 D）；
    - SF_SINK_PROBE：探针。
  - 生成器 `hold_gen_sinkpos.py`（`hold_gen_long_rr.py` 的副本，加了 `--sink_mode` 和 `--probe`）。
- **一致性检查：** 不开开关时，Self-Forcing-b 生成的 rx00（sink 3，m16，A40）与预注册 10 的输出逐位相同（`IDENTITY True 0.0`）。
- **探针：**
  - 对选定的块，每次注意力调用（4 个去噪步 + 1 次上下文，30 层）取 128 个固定的随机查询（torch.Generator 种子 0，不消耗全局随机数）；
  - 对网格中的每个距离 D，把 sink 的键旋转到"最新查询帧到 sink 第 0 帧的距离为 D"的位置；
  - 计算 sink 的 logsumexp 与窗口的 logsumexp，得到查询会分给 sink 的注意力份额，在查询上平均，每个头单独保存；
  - 只读，不改变生成。
- **设置：** 4 个未平移的开头（rx00、rx01、gx00、gx01），sink 3，原始位置；块起点 12、24、…、240（20 个块）；距离 3–300。
- **作业：** `jobs/run_sinkprobe.sh`，A40，约 2.3 小时。
- **分析：** `analyze_sinkprobe.py`：在头、层、调用、块和开头上平均；用 3 点平滑后高于中位数的局部最大值作为峰。

## 结果（`results/corr/sinkprobe_out/sinkprobe_out.json`）
- sink 份额在距离 3 处最高（0.19，sink 紧挨当前块），随距离下降到约 0.07，之后有四个尖峰：

| 距离 D | 份额 | 原始位置下到达这个距离的时刻 |
|---|---|---|
| 71 | 0.109 | 16.5 秒 |
| 134 | 0.136 | 32.25 秒 |
| 203 | 0.150 | 49.5 秒 |
| 266 | 0.098 | 65.25 秒 |

- 3 ≤ D ≤ 300 的中位数为 0.073。每个峰宽约 4 个潜在帧，峰之前有谷（D = 123 处 0.055，D = 187 处 0.052）。
- 在每个开头、每个块上，峰都在完全相同的距离（71、134、203、266），所以这是模型位置编码的性质，与内容无关。
- 峰在每次去噪调用中都存在（第 1 步最强：D = 203 处 0.163；上下文调用 0.134），在不同层的强度不同（第 0、8、12、14、23、27 层最强）。
- 实际生成中的自然距离（块起点 132，距离 134）对应的份额为 0.184。
- 次级峰（D ≈ 103–108 处 0.087，≈ 175 处 0.086）对应原始位置下约 25 秒和 42 秒，这正是持续度曲线上的小凸起。
- **时间换算：** 从潜在帧 c 开始的块，到 sink 第 0 帧的距离是 c + 2，它从开头之后 (c − 3)/4 秒开始，所以距离 D 对应 (D − 5)/4 秒。
  - 前三个峰对应 16.5、32.25、49.5 秒，正是突跳的时刻。
- **旋转频率：** 峰的间隔是 63–69 帧，不等距，而 Wan 的时间旋转频率（22 个，周期 2π·10000^(j/22)：…, 51.0, 77.5, …）中没有一个周期是 67。论文原来"接近某个频率的周期 70.6"的说法不对，已删除。峰的位置应来自多个频率与学到的查询–键结构的组合，这里不做进一步分解。

## 设计问题（预注册 25 的次要分析）
- 预注册 25 的探针对照（1 秒 α 曲线的一阶差分与探针份额的一阶差分的相关）只用了 lag 0。
- 突跳窗口从 τ + 0.5 秒开始，1 秒 α 曲线要在份额达到峰值之后 1–2 秒才上升。用模拟数据核对：即使突跳完全按预测出现，lag 0 的相关也接近 0 或为负（r = −0.17），lag 1、2 秒为 +0.46、+0.58。
- 所以预注册 25 的这项次要分析不能用来检验探针；预注册 26 改为报告 lag 0–3 秒。解读预注册 25 时会说明这一点。
