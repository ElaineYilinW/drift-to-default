# 确认性实验结果：参考内容的变暗校正（2026-10-19）

**结论：预注册的全部判定标准都满足。** 在开发阶段从未用过的 40 个正式 prompt 上，免训练的"参考内容"校正（去噪第 1 步，只看锚定帧的参考前向，迁移 16 个通道的均值差）显著减少了颜色漂移和变暗，没有伤害结构，在新写的对照上也基本保留了正常的亮度变化。代价是一定的闪烁。

## 数据
- 576 段视频，没有缺失：
  - 漂移集：40 个 prompt × 4 个 seed × 3 组（不校正、β = 1、β = 1.5）= 480 段；
  - 对照集：8 个新写的对照 × 4 个 seed × 3 组 = 96 段。
- 全部在 A100 80GB / A800 40GB 上生成（二者逐位一致），同一 prompt 的各组严格配对。
- 分析脚本 `analyze_confirm.py` 的 SHA-256 与预注册中冻结的一致（a5363d5c…）。没有偏离预注册。

## 正常变化保留（新写的 8 个对照）
- 按预注册规则，"山间日落"被排除：不校正组的平均 |首末亮度差| 只有 3.9 L，小于 5 L，模型没有产生明显的转换。其余 7 个有效。
- 保留比例的中位数：**β = 1 为 0.83，β = 1.5 为 0.93**。两者都达到 ≥ 0.80 的标准。

## 解读和局限
- 两个强度之间是一个**取舍**：β = 1.5 去漂移更多，也更能保留正常的亮度变化；但段边界的闪烁约为 2.4 倍。β = 1 的闪烁很小，去漂移略少。实际使用时取决于对闪烁的容忍度。
- **只解决了颜色和亮度**：结构漂移 K 没有改善（也没有变差）。肉眼检查中，长视频后段天空的纹理伪影依然存在。
- 只在一个模型（Self Forcing 1.3B，窗口 21 + 锚定 3 帧）和 31 秒的长度上验证过。
- 对照的保留比例在不同 prompt 之间差别较大（0.58–1.71），有 7 个有效对照，统计精度有限。
- 计算代价：校正的每段多一次前向，约增加 25% 的生成计算。
- 和已有方法的关系：思路来自 Pathwise TTC（只用锚定帧做参考）和 FreqForcing（色彩漂移集中在低频），本方法是两者的简化组合：只迁移 DC 分量，只在第 1 步做一次，不重新加噪。开发阶段发现的"去噪步骤就是内容感知程度的旋钮"（第 0 步会抹掉正常变化，第 2、3 步无效），据我们所知前人没有系统报告过；但没有为此做专门的文献核查。
