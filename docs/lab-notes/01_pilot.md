# 预实验报告（2026-10-18）

## 设计
- 模型：Self Forcing（Wan2.1-T2V-1.3B，DMD，4 步），Argon 上的 A40 显卡。
- 10 个 prompt：5 个 MovieGen（mg001、004、018、027、035），5 个驾驶场景（郊区、高速、市中心、雨天、雪天）。每个 prompt 用 3 个 seed（0、1、2）。
- 4 种策略：窗口 21 或 12 个潜帧 × sink 0 或 3 个潜帧。视频长 501 帧，约 31 秒。
- 同一个 seed 下，所有策略的初始噪声和采样随机数完全相同，所以是**配对设计**：窗口滚动之前，所有策略的画面完全一样。
- 参照分布：每个 prompt 用 10 个 seed（100–109）各生成一段 81 帧的短视频，全局注意力，不滚动。
- 漂移指标 D：把每一帧概括成 5 个特征（Lab 色彩空间的 L、a、b 均值，饱和度均值，log 清晰度），计算这些特征到同一 prompt 参照分布的 Mahalanobis 距离，再按 1 秒一段取平均。另外看每个特征带符号的 z 分数。
- 代码：`gen.py`、`analyze_pilot.py`；结果在 `results/pilot/`（summary.json、curves.png、segments.csv、抽帧图）。

## 结果

**1. 校准没有问题。** 前几秒 D 约为 2.4，参照分布自身的留一 seed 距离中位数是 2.7，95% 分位数是 5.0。也就是说，长视频刚开始时确实处在"正常输出"的分布里。

**2. 最后 2 秒的漂移 D**（均值，按 prompt 和 seed 两层 bootstrap 的 95% CI）：

| 策略 | D | 超过正常范围的比例 |
|---|---|---|
| w12s0（窗口 12，不锚定） | 15.2 [9.9, 22.7] | 93% |
| w21s0（窗口 21，不锚定） | 8.6 [6.5, 10.9] | 80% |
| w21s3（窗口 21，锚定 3 帧） | 5.8 [4.5, 7.2] | 53% |
| w12s3（窗口 12，锚定 3 帧） | 5.6 [4.4, 6.8] | 57% |

和 w21s0 的配对差异：w21s3 −2.8 [−4.4, −1.3]；w12s3 −3.1 [−5.1, −1.3]；w12s0 +6.6 [+1.5, +13.4]。

**3. 窗口大小和锚定有交互作用。** 不锚定时，小窗口漂移更严重；锚定之后，窗口大小几乎没有影响。注意 MotionStream 报告的是"窗口越大越差"，和这里方向相反，但它的任务和视频长度都不同。

**4. 锚定能减慢漂移，但不能消除。** 锚定后最后 2 秒仍有 53–57% 超出正常范围，和 FreqForcing 的结论一致。

**5. 漂移的方向是一致的，说明是系统性漂移，而不是内容变化。**
- 变暗：所有策略最后 2 秒的 z_L 有 93–100% 为负。**锚定也没能阻止变暗**，z_L 约为 −2.5。
- 过饱和：只在不锚定时出现，z_sat 有 73–80% 为正；锚定后只有 33–43% 为正，相当于消失了。
- 变冷（b 值下降，黄色减少、偏蓝）：所有策略都有。

**6. 变异来源。** 不锚定时，变异主要来自 prompt：w12s0 的 prompt 方差是 86.5，seed 方差是 39.2。最差的例子是 drive_downtown 在 w12s0 下 D 达到 32–53，画面完全崩坏成霓虹色块。锚定之后，prompt 方差和 seed 方差相当。

**7. 功效分析**（以配对的锚定效应 −2.8 为基准，双侧 α = 0.05）：
- 效应和预实验一样大：10 个 prompt × 3 个 seed 的功效已经有 98%。
- 效应减半：20 × 5 为 92%，40 × 3 为 98%。
- 效应只有四分之一：60 × 5 为 83%。

**8. 和前人指标的对比。** 首末帧色差 ΔE 和 ID-Forcing 色彩指标的排序与 D 一致，但它们几乎**分不出**窗口大小的差异：ΔE 在 w12s0 和 w21s0 下分别是 18.2 和 17.7，而 D 分别是 15.2 和 8.6。

## 肉眼检查（抽帧图 `contact_*.jpg`）
- 颜色指标 D 和肉眼看到的颜色问题一致：w12s0 崩坏成霓虹色块，w21s0 变暗、对比度升高、变冷。
- **D 漏掉了另一类退化：结构和纹理。** drive_downtown 在锚定策略下，31 秒时出现白色噪点状的天空，建筑结构也有扭曲，但 D 只有 1.4–4.4。原因是 D 只看全局颜色统计。

## 对正式实验的决定
1. **增加第二个主要指标**，用来捕捉结构和纹理的退化：用 DINOv2 特征，计算与同一 prompt 参照分布的距离（KID 或 Fréchet）。同时计算 MUSIQ，对应 Rolling Forcing 的 ΔDrift，方便和前人比较。**颜色漂移（D）和结构退化（DINOv2）分开报告。**
2. **规模**：40 个 prompt（20 个驾驶 + 20 个 MovieGen）× 4 个 seed。即使效应只有一半，功效也超过 95%；交互作用和小效应也有合理的功效。
3. **策略**：窗口 {12, 21} × sink {0, 1, 3}，再加"sink 重新旋转位置编码"（RoPE re-rotation）的版本，用来区分"锚定有用"和"位置编码处理方式的影响"。
4. **正式生成前写好预注册**：假设、主要指标、分析模型和判定标准。
