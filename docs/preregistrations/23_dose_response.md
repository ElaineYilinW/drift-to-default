# 预注册 23：弛豫是不是线性响应？色调持续度的剂量–反应（Self Forcing，60 秒）（2026-10-28，生成前冻结）

## 背景
- 论文的核心关系 x∞ ≈ α·x_open + (1 − α)·μ 对开头是线性的：α 被当作模型和"开头如何被保持"的性质，与开头被改动了多少无关。
- 但论文里所有色调 α 都只用一对平移（L\* −16 / +16）估计。
- 如果 α 随平移大小变化（例如很暗的开头被当作夜景，或者某一侧接近饱和），α 就只是一个局部线性化，论文里"无 sink 完全遗忘""重新旋转的 sink 保留约 0.2"这些说法也只在 ±16 成立。
- 已有的唯一剂量检验（实验记录 05）只在 KV 窗口里对单个块做 ±2 / ±5 / ±10 的平移，时间很短（α 为 0.67 / 0.75 / 0.79，随剂量略增），没有检验开头在 60 秒时的持续度。
- 本研究对同一批场景施加五个大小不同的平移，检验三件事：
  - α 是否与平移大小无关；
  - 变暗和变亮是否保留得一样多；
  - 无 sink 时，大的平移是否也被完全遗忘。

## 设计
- **场景：** 预注册 06 的 24 个场景（rx00–rx11、gx00–gx11），通用提示词（`prompts/relax.jsonl`）。
  - 开头的平均 L\* 约为 35–50。−24 时约为 11–26（很暗），+24 时约为 59–74。
- **模型：** Self Forcing DMD，60 秒（243 个潜在帧），`hold_gen_long_rr.py`（与预注册 10、16、20 相同）。
- **条件：**
  - sf60_s3：sink 3，原始位置；
  - sf60_s0：无 sink；
  - sf60_s3rr：sink 3，重新旋转。
- **开头：** 在 CIELAB 中把开头图像的 L\* 平移 −24、−8、0、+8、+24（版本名 m24、m8、z0、p8、p24），然后再进行 VAE 编码（与之前的研究相同）。
  - 0 平移的版本直接使用原图，不做 Lab 往返转换。
- **种子：** 0、1。
- **执行：**
  - 每个场景 × 种子一个任务，包含所有条件和版本（15 个视频）；
  - 每个种子写到单独的文件夹，arch_guard 保证一个场景在该文件夹里的所有输出来自同一 GPU 架构；
  - GPU 不限型号（≥ 40 GB，支持 bf16）；
  - 任务清单由 `make_s23_tasks.py` 生成（`jobs/s23.jsonl`）。
  - 共 24 × 3 × 5 × 2 = 720 个视频。

## 指标
- 对每个场景、条件、种子和版本 v：
  - open_v：第 1–8 帧的 L\* 均值；
  - end_v：开头之后 [T − 10, T) 秒的 L\* 均值（16 fps）。
- 对一对版本 (hi, lo)：α(hi, lo) = (end_hi − end_lo) / (open_hi − open_lo)。若 open_hi − open_lo < 4 L\*，则无定义。
  - α_small = α(p8, m8)；
  - α_large = α(p24, m24)；
  - α_up = α(p24, z0)；
  - α_down = α(z0, m24)。
- 场景的值：该场景所有种子的均值。
- 没有坍塌排除规则（与预注册 10、20 相同）。

## 假设（`analyze_s23.py`，冻结；Holm 校正，共 4 个检验；T = 60 秒）
- **D1 sink 3 的持续度与平移大小无关：** α_large − α_small 在 ±0.15 之内。
- **D2 重新旋转的 sink 3 也一样：** α_large − α_small 在 ±0.15 之内。
- **D3 sink 3 对变暗和变亮保留得一样多：** α_up − α_down 在 ±0.15 之内。
- **D4 无 sink 时大的平移也被遗忘：** α_large(sf60_s0) 在 ±0.10 之内。
- **检验方法：**
  - 等价检验：以场景为单位，对边界做两个单侧 t 检验（TOST），p 取两者中较大的一个；
  - Holm p < 0.05 为成立；
  - 95% CI 用场景 bootstrap（10,000 次），同时报告 90% t 区间。
- **边界的选择：**
  - 0.15 小于论文解读的最小条件差别（重新旋转的 sink 比无 sink 多保留约 0.2）；
  - 0.10 是"完全遗忘"的操作定义。

## 次要分析
- [40, 50) 秒窗口的 D1–D4；
- 每个条件在 10、20、30、40、50、60 秒的 α_small、α_large、α_up、α_down；
- 对每个场景、条件和种子，用五个开头对 end(60) 关于 open 做最小二乘拟合：
  - 斜率和 R²；
  - 以中心化的 open 做二次拟合，二次项系数按条件对 0 检验；
- 每个种子单独的 D1–D4 估计；
- 每个条件小、大两对的 31→34 秒跳变：α([34, 35)) − α([31, 32))，以及两者之差（跳变是否与平移成比例）；
- 吸引子偏移：每个条件 z0 版本的 end(60) − open；
- 预注册 10、16、20 中同一场景、条件、种子的 α_16 = α(p16, m16)，与 α_small、α_large 并列（描述性）；
- 每个条件和开头中，1 秒平均 L\* 低于 3 或高于 97 的视频数（坍塌；不排除）。

## 预测
- **D1、D2 成立：** 论文的线性关系预测 α 与平移大小无关。KV 窗口的剂量检验中 α 随剂量略增（0.67 → 0.79），所以 α_large 可能比 α_small 略大，但在 ±0.15 之内。
- **D3：** 不确定。很暗的开头（L\* 约 11–26）可能被当作夜景，向默认值的拉力与较亮的开头不同。若不成立，则线性关系只在开头附近的一个范围内成立。
- **D4 成立：** 无 sink 时 α 在 60 秒约为 0（预注册 20：−0.01）。
- 若 D1 或 D2 不成立，论文中的 α 应写成对 ±16 平移的持续度，而不是模型的常数。
