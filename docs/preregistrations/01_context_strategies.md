# 预注册：Self Forcing 长视频漂移的条件帧策略比较（2026-10-18）

写于正式实验数据分析之前。正式视频已经开始生成，但在本文件冻结之前，只检查过完成数量，没有看过任何正式数据的内容或指标。
所有设计决定都来自预实验（`docs/pilot_report_cn.md`），预实验的 prompt 不在正式实验中重复使用。
分析代码 `analyze_main.py` 和本文件同时冻结。冻结时两者的 SHA-256 记录在文末。

## 1. 设计
- 模型：Self Forcing DMD 检查点（Wan2.1-T2V-1.3B），4 步采样，bf16，A40 显卡。sink 重新旋转的实现见 `jobs/patch_sf.py`。
- Prompt：40 个（`prompts/main.jsonl`）。
  - 20 个 MovieGen：从 1003 个 prompt 中排除预实验用过的 5 个，用 `numpy.random.default_rng(2026)` 随机抽取，使用扩写版本。
  - 20 个驾驶场景：自行编写，覆盖不同时段、天气和道路类型。
- Seed：0、1、2、3。同一个 seed 下，所有策略的初始噪声和采样随机数相同（配对设计）。
- 视频长度：126 个潜帧，即 501 帧，16 fps，约 31 秒。
- 10 种策略：
  - 窗口 {21, 12} × sink {0, 1, 3}，共 6 种；
  - 再加上重新旋转版本：窗口 {21, 12} × sink {1, 3}，记为 w*s*r，共 4 种。
- 参照分布：每个 prompt 用 seed 100–109 各生成一段 81 帧的短视频，全局注意力，不滚动。

## 2. 指标（都在 `analyze_main.py` 中实现）

**M1 颜色漂移 D（主要指标）**
- 每帧取 5 个特征：Lab 的 L、a、b 均值，HSV 饱和度均值，log(拉普拉斯方差 + 1)。
- 用同一 prompt 参照帧的均值和协方差，计算每帧的 Mahalanobis 距离，再按 1 秒一段取平均。

**M2 分布漂移 K（主要指标）**
- 对每 4 帧取一帧，计算 DINOv2-base 的 CLS 特征并做 L2 归一化。
- 计算它到同一 prompt 参照帧的 5 个最近邻的平均余弦距离。
- 除以参照帧自身的留一 seed 同类距离的中位数，按 1 秒一段取平均。
- 解释：K 度量"偏离该 prompt 的正常输出分布"的程度。它既包含画面退化，也包含内容逐渐偏离 prompt，**不区分这两者**。

**次要指标和与前人可比的指标**
- 带符号的 z 分数：z_L、z_sat、z_b。
- MUSIQ-SPAQ 的 ΔDrift = |前 5 秒均值 − 后 5 秒均值|，按 Rolling Forcing 的定义。
- ID-Forcing 的色彩指标 = 100·(1 − ½‖h_first − h_last‖₁)。
- 首末帧色差 ΔE。

**终点**：第 29–31 秒（最后 2 秒）的段均值。

## 3. 假设和检验

统计模型：对每个指标的终点，拟合线性混合模型 y ~ strategy + (1 | prompt) + (1 | prompt:seed)，用 REML 估计。检验下列线性对比，使用 Wald 检验。

**主要假设族**（M1 和 M2 各检验 2 个，共 4 个检验，Holm 校正，α = 0.05）：
- **H1 锚定降低漂移**：C1 = ½[(w21s3 − w21s0) + (w12s3 − w12s0)] < 0。
- **H2 窗口 × 锚定交互**：C2 = (w12s0 − w21s0) − (w12s3 − w21s3) > 0。也就是说，不锚定时小窗口更差，锚定后这个差距缩小。

方向性假设用单侧 p 值。只有当 Holm 校正后 p < 0.05，且 95% CI 的方向与假设一致时，才判定"支持"。

**次要分析族**（Holm 校正，双侧检验）：
- C3 重新旋转的效果：½[(w21s3r − w21s3) + (w12s3r − w12s3)]，分别在 M1 和 M2 上检验。
- C4 锚定帧数量：½[(w21s3 − w21s1) + (w12s3 − w12s1)]，分别在 M1 和 M2 上检验。
- **H4 锚定后仍然变暗**：在 w21s3 和 w12s3 的视频里，最后 2 秒 z_L 的均值 < 0。以 prompt 为单位做单样本 t 检验，单侧。

**稳健性和探索性分析**（不做判定）：
- 用 bootstrap 重算 C1–C4 的 CI：先按 prompt 重抽样，再在 prompt 内按 seed 重抽样，B = 2000。
- 驾驶和 MovieGen 两个子集分别分析。
- 漂移随时间的曲线。
- 方差分解：prompt 和 seed 各贡献多少变异。
- 前人指标和 M1、M2 的一致性，包括 MUSIQ 是否偏爱过饱和的画面。
- 观察 sink-collapse（画面被拉回锚定帧的内容）是否出现。
