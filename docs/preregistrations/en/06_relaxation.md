# Preregistration: "relaxation" in long-horizon autoregressive generation — how much of the opening is retained, where it goes, and how attention sinks and correction change it (2026-10-23, frozen before generation started)

## Background and theory
Existing result: drift is a regression to the default level set by the prompt. On existing data, exploratory analysis showed the same regression for brightness, a\*, b\*, saturation, sharpness and contrast (correlation between the opening value and the change of −0.8 to −0.95, in both models). Persistence first drops quickly over time, then levels off at around 0.3–0.4.

In the sink 3 setting, the fixed opening chunk is itself the sink. From this we propose a testable mechanistic model:

  long-horizon state ≈ α·opening + (1 − α)·μ_prompt

- α: the share of the opening that is retained. In theory, the sink keeps the opening in the context permanently, so α > 0. Without a sink, the opening leaves the window after about 5 seconds, so α should be close to 0.
- μ_prompt: the default level set by the prompt.

This model unifies all earlier results: the sink and content-aware correction raise α; calibrated prompts move μ_prompt closer to the opening.

All earlier evidence was observational: it compared opening brightness across different scenes, and dark scenes and bright scenes also differ in content. This experiment directly manipulates the brightness and color temperature of the opening **within the same scene**, giving interventional estimates.

## Design
- **Scenes:** 24 base scenes (`select_relax_openings.py`; rules fixed before generation).
  - 12 real scenes: NAVSIM logs not used before, with opening brightness chosen at equal spacing between 35 and 50.
  - 12 generated scenes: frame 0 of the driving prompts with seed 2 from the Self Forcing confirmatory experiment, taking the 12 whose brightness is closest to 42.
- **Opening versions (7 per scene):** a controlled shift of the image in CIELAB, which is then encoded by the VAE.
  - L\*: −16, −8, 0, +8, +16
  - b\*: −12, +12 (L\* unchanged)
- **Prompt:** all use the generic driving prompt of the earlier real-opening experiment. Seed 0. The 7 versions of the same scene and the same configuration are generated in the same task, on the same GPU.
- **Configurations (model × context strategy):**
  - sf_s3 / sf_s0 / sf_ttc: Self Forcing DMD, window 21, sink 3 / sink 0 / sink 3 with correction (step 1, β = 1). The three run in the same task.
  - sid_s3, sidv2_s3, gan_s3, sf10s_s3: the other training objectives released by Self Forcing (SiD, SiD v2, GAN, 10-second training), window 21, sink 3. The student model initialized by ODE regression collapsed into blurry frames right after the opening in the smoke test. Its color statistics reflect the collapse, not drift, so it was removed before freezing and replaced by SiD v2.
  - cv_s3: CausVid (autoregressive_checkpoint, 3 steps [1000, 757, 522], shift 8, no warp; frames normal in the smoke test), window 21, sink 3.
  - ll_s3 / ll_s0: LongLive, window 12, sink 3 / sink 0. The two run in the same task.
  - rf: Rolling Forcing (anchor fixed to the opening block).
  - sky: SkyReels-V2-DF 1.3B (diffusion forcing, 24 fps, 544p, 30 steps, CFG 6). In the smoke test an 8-second video took 13 minutes, so only a reduced design is run: every other scene, 12 scenes in total; only the three versions L\* −16, 0, +16; duration 20 seconds.
- **From-scratch controls:** for every configuration except sky, generate 31 seconds with the generic prompt, 4 seeds and no fixed opening. Used to compare the default level with the endpoint level reached from scratch.
- **Long-horizon subset (secondary):** the three configurations sf_s3, sf_s0, ll_s3 × 6 scenes × L\* ±16, generated for 120 seconds.

## Execution details
- Even-numbered scenes are pinned to A40, and odd-numbered scenes to L40S / RTX 6000 Ada (the same architecture). All versions of the same scene and configuration run in the same task, so resuming after preemption does not change the architecture. The task lists are generated by `make_relax_tasks.py` (`jobs/relax_a40.jsonl`, `jobs/relax_l40s.jsonl`).
- With no perturbation and no checkpoint change, `hold_gen.py` gives output bitwise identical to the earlier frozen `correct_gen2.py` (checked in the smoke test).

## Metrics
- Opening value: the mean over the fixed frames (excluding frame 0). Endpoint value: the mean over the last 2 seconds. Attributes: L\* (primary), b\* (primary), a\*, saturation.
- Persistence α: within each scene, regress the endpoint value on the opening value by OLS and take the slope; then average across scenes.
  - α_L is estimated from the 5 L\* versions.
  - α_b is estimated from the three b\* versions −12, 0, +12.
- Default level: the point on this line, for the same scene, where "endpoint = opening".
- Time course: compute α(t) once per second, then fit α(t) = α∞ + (1 − α∞)·exp(−t/τ).

## Hypotheses (primary; Holm correction over 4 tests)
- H1: α_L(sf_s0) < α_L(sf_s3). The sink keeps the opening in the context.
- H2: α_L(ll_s0) < α_L(ll_s3). Replication of H1 on a second model.
- H3: α_L(sf_ttc) > α_L(sf_s3). Content-aware correction raises the retained share.
- H4: α_b(sf_s0) < α_b(sf_s3). H1 generalized to color temperature.

**Test method:** for each scene, compute the difference in slope between the two configurations, run a two-sided one-sample t-test, and give a 95% CI by scene bootstrap. Decision rule: Holm p < 0.05, and the direction matches the expectation.

## Secondary analyses (estimates and CIs only)
- α_L, α_b, α_a, α_sat and the default level for each configuration; α(t) curves, and the half-life τ·ln2 and α∞.
- Comparison across training objectives and models (DMD, SiD, SiD v2, GAN, 10s, CausVid, LongLive, Rolling Forcing, SkyReels). The α of sky is evaluated at 20 seconds and compared with the α(t) of the other models at 20 seconds.
- Comparison of the default level with the endpoint level reached from scratch.
- Whether, without a sink, α_L at 31 seconds is below 0.2 (close to complete forgetting).
- α_L of the long-horizon subset at 30, 60, 90 and 120 seconds.
- Out-of-sample quantitative test: use α_L(sf_s3) estimated in this experiment, together with the per-prompt default levels from Part 4, to predict the results for each opening frame in the Part 6 calibrated-lighting experiment (these data already exist). Report R² and correlation.
