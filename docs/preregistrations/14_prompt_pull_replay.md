# 预注册 14：直接测量提示词每段的拉力 w_p（2026-10-24，生成前冻结）

## 背景
- 链式递推模型：x_{k+1} = w_w·窗口均值 + w_s·sink + w_p·μ，且 w_w + w_s + w_p = 1。平衡时保留的比例是 α∞ = w_s/(w_s + w_p)。
- w_s 和 w_w 已用 KV-cache 重放直接测量过（w_s ≈ 0.053；w_w 合成平移 0.76、自然差异 0.90–0.99）。但 w_p 从来没有直接测过，只是 1 − w_w − w_s 的余项。
- 用 120 秒曲线拟合的参数（w_s = 0.060，w_w = 0.86）推出 w_p ≈ 0.08。本研究直接测量 w_p，检验这个预测。

## 设计
- **模型：** Self Forcing DMD，窗口 21，sink 3 和无 sink；通用提示词下从零生成 31 秒（种子 0–15，每个 sink 16 个视频）。
- **干预：** 在第 k 段（k = 8、20、40，即约 6、15、30 秒）之前，保留 KV cache、随机数状态和噪声，只把文本条件换成另一个提示词 B（晴天、阴天、黄昏、夜晚；各自独立的 cross-attention cache），重新生成第 k 段；然后恢复 cache，继续原视频。B = 通用提示词时必须逐位复现原段（已在冒烟测试中确认，最大差 0）。
- **测量：** 第 k 段解码后的平均 L\*；ΔL = L_k(B) − L_k(通用)。
- **提示词的默认值 μ：** 灯光实验（实验记录 06）在 Self Forcing 上的零漂移亮度：通用 33.1、晴天 42.9、阴天 33.6、黄昏 19.1、夜晚 16.0。
- **估计：** 对每个种子和 k，把 ΔL 对 Δμ = μ_B − μ_通用（4 个提示词）做过原点的最小二乘，斜率即 w_p。
- **执行：** `pswap.py`，任务清单 `jobs/pswap.jsonl`（每个任务 4 个种子；同一视频的所有替换都在同一次运行里，天然配对）。

## 假设（`analyze_pswap.py`，冻结）
- **主要假设：** w_p(sink 3, k = 20) > 0（以种子为单位的双侧单样本 t 检验，p < 0.05 且估计 > 0）。
- **定量预测（次要）：** w_p(sink 3, k = 20) 落在 [0.04, 0.14] 内（由 120 秒拟合推出的 0.08）。
- **次要分析：** sink 3、无 sink 在 k = 8、20、40 的 w_p；w_p(k = 40) − w_p(k = 8)（时间不变性）；闭合检验 w_s + w_w + w_p（w_s = 0.053，w_w = 0.76 或 0.86）；每个提示词的 ΔL/Δμ；阴天（Δμ ≈ 0）的 ΔL 作为安慰剂；重放检验。95% CI：种子 bootstrap。
- **预测：** 主要假设成立；w_p 在预测区间内。
